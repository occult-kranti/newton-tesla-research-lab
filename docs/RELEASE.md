## Rendering and image boundaries

The accepted scientific views use executable coordinates and equations. One image-generator attempt introduced unsupported mechanical/wiring details and was rejected; its review is preserved separately. It is not the default experiment plate.

Local browser rendering was unavailable. Public desktop inspection is performed after deployment and recorded in `docs/deployment.json` when available. The exposed browser API provides no viewport-resize control; responsive CSS and DOM checks do not amount to rendered mobile-device verification. No mobile screenshot or screen-reader speech test is claimed.

The requested historical/astronomical Pages URLs could not be retrieved by the research fetch tool. Their pinned local source and existing sanity suite were inspected; live behavior and independent high-precision ephemeris accuracy were not verified. No whole-site import was made.

## Next concrete work

Follow the [stepwise roadmap](roadmap.md). First characterize actual components and synchronized voltage/current channels on a low-voltage coupled circuit. Then test a known injected drive, deliberately failed phase calibration and an independently characterized witness. Keep all raw data and failures. A witness channel must have measured transfer, loading and signal leakage; calling it a reference does not establish those properties.

The current calculations identify effective model quantities conditionally. An unmonitored ordinary drive at the same port can reproduce the hypothetical exotic contribution. Physical-source identification needs a model and an independently calibrated observation or intervention whose predictions differ. The three-round program stops here; no extra numerical round is hidden in publication work.
